# Finance Study Workbench · 金融学习工作台

一个可以独立运行的本地学习项目：先回想金融英语或小题答案，再揭示、判断，让错误进入后续复习。按剩余首轮词量倒排每日计划，保存逐次判断，并支持备份恢复。

包含8个自编金融英语词项与2道自编小题，内容与应用原创部分MIT。FSRS使用上游MIT模块。示例用于展示工作流，不是完整考试题库或教材。

## 运行

需要 **Node 24 或更新版本**（使用内置 `node:sqlite` 与TypeScript类型擦除）。没有运行时npm依赖，也不需要Python、模型密钥或外部服务。

```sh
npm ci
npm start
# http://127.0.0.1:8878
```

启动前会检查类型并编译浏览器入口。服务只绑定本机，数据新建在本项目 `data/learning.sqlite`；不要把旧应用的数据库复制到这里。停止后再启动，当前组、判断与记忆状态仍在。若端口被占用可自行指定：

```sh
STUDY_PORT=8879 npm start
```

这是一套单人本地工具；同一服务的不同标签页/浏览器共用记录。没有在线账号或同步服务，也没有部署到个人网站。请在自己的本地运行，不将这个本机服务直接作为公网多用户平台。

## 窄工作流

1. **今日计划**：设置开始日、目标日、考前只复习天数、每组数量。默认从当天起60天，最后7天只复习；所有日期可修改，没有个人考试日期硬编码。
2. **隐藏答案**：进入一组只显示题面。词项先自己回想，选择题先选选项；点击或↓揭示不计分，其他区域也不会提前显示解释。
3. **主动判断**：揭示后←记错、→记对；题目选项不符即使自判记对，也以记错记录。记错后停留看解释，再→/↓前进，前进不重复评分。跳过也不评分。
4. **复习接续**：上一组错词优先，其他到期内容其次，再安排新词。错后从离开反馈起至少10分钟；跨组累计第1/2/3/4次正确后等1/3/7/14天，第5次后FSRS接续。过程中再错保留正确次数、重新等10分钟，通过后再错重开0/5。首次记对直接进入FSRS。
5. **记录与恢复**：判断与进度同一SQLite事务；重复请求只执行一次，旧revision/turn被拒绝。导出备份后，可查看记录或恢复同一词库的备份。恢复替换当前进度，但原始判断事件按ID合并保留并追加恢复记录。

数量计划按北京时间划日：剩余未首轮项加上今日已完成新词，均摊到新词截止日前；今天做完一项不会降低当天目标。复习次数与新词数量分开，首轮进度不是掌握率。等待中的上一组错词可能暂时挡住新词，界面会说明等待原因。

默认示例仅10项，60天计划通常每天只需1个新词。想快速检查一整组，可在尚未开始时将目标日期设为明天、冲刺天数设为0、组量设为5；这只调整自己的新项目计划，不改任何现用学习系统。

## 数据与许可边界

- 只加载本仓库 `content/deck.json`。替换时保持明确授权，填写自身词库ID、许可、词卡ID/题面/释义/解释；选择题还需选项与正确选项。结构由 `validateDeck` 校验。
- 首次学习前可用自有词卡替换示例。已有进度后变更词卡ID会使旧备份不匹配，应先导出，再单独建立一个干净实例；不要假装旧成绩适用于新内容。
- 未包含原教材、原题、PDF/OCR、个人学习数据库、授权映射、访问凭证或发布脚本。只接受本项目备份，不能拿个人旧应用备份直接恢复。
- 进度/备份可能包含使用者自己的学习行为，不应提交到Git。`data/`、SQLite和构建物已忽略。
- 不调用AI、不上传内容。GitHub上的自编样例源码是公开的；隐藏答案是学习交互，不是防作弊考试系统。

FSRS版本、原版权、核验哈希与原创增量详见 [UPSTREAM.md](UPSTREAM.md)。

## 开发与验证

```sh
npm run format:check
npm run lint
npm test
npm run build
npm run verify:vendor
```

`build`包含严格TypeScript检查，启用 `erasableSyntaxOnly`，避免参数属性等Node直跑不支持语法。测试真实调用调度函数、SQLite和随机端口HTTP服务；复习时间由固定时钟推进，不将10分钟规则改短。测试目录是临时新建的，不指向任何已有数据库。

本地已运行上述检查；GitHub CI是否通过应以相应PR实际运行记录为准。贡献和代码审查流程见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 代码入口

| 层         | 文件                                | 作用                                           |
| ---------- | ----------------------------------- | ---------------------------------------------- |
| 调度与计划 | src/core.ts                         | 状态转移、逐次判断、跨组策略、FSRS与每日数量   |
| 输入边界   | src/validation.ts                   | 词库、设置、命令、记忆和恢复状态校验           |
| 持久化     | src/store.ts                        | SQLite事务、revision、幂等请求、追加事件与恢复 |
| 输出边界   | src/view.ts / src/http.ts           | 按阶段裁剪答案、HTTP与静态文件白名单           |
| 界面       | web/app.ts / index.html / style.css | 计划、隐藏答案、判断、记录及备份               |

当前不包含多用户身份、撤销/改判、在线题库导入、云同步或课程资料阅读器。可以在稳定ID与许可明确的内容上继续扩展。
